# Notices

## FreeSurferColorLUT

`config/FreeSurferColorLUT.txt` is an annotated derivative of the FreeSurfer
color lookup table. The FreeSurfer label IDs, label names, and color values are
preserved; NeuroCade added inline explanatory comments for application display
and assistant context.
